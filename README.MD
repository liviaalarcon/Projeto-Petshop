# 🧠 Jogo da Memória 💖

Um jogo da memória simples, divertido e fofo, desenvolvido com **HTML, CSS e JavaScript puro**.

O objetivo é encontrar todos os pares de cartas antes que o tempo acabe. 🎀

## 🎮 Como Jogar

1. Clique em uma carta para virá-la.
2. Clique em outra carta.
3. Se as duas cartas forem iguais, você encontrou um par! ⭐
4. Se forem diferentes, elas voltarão a ficar fechadas.
5. Encontre todos os pares antes do tempo terminar.
6. Ao vencer, você recebe pontos extras de acordo com o tempo restante. 🏆

## ✨ Funcionalidades

* 🃏 16 cartas e 8 pares
* 🔀 Cartas embaralhadas a cada partida
* ⭐ Sistema de pontuação
* 🎯 Contador de tentativas
* ⏱️ Cronômetro de 60 segundos
* 🏆 Tela de vitória
* ⏰ Tela quando o tempo acaba
* 🔄 Botão para reiniciar o jogo
* 💖 Interface colorida e fofa
* 📱 Design responsivo para celular e computador
* ✨ Animação ao virar as cartas
* 🐱🐶🐰🦄 Emojis divertidos

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura do jogo
* **CSS3** — visual, animações e responsividade
* **JavaScript** — lógica, cartas, pontuação e cronômetro

Não é necessário instalar nenhuma biblioteca ou framework.
